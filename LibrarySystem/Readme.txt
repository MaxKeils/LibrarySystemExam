**Часть 2. Напишите модульные тесты**

Используя MSTest, напишите тесты для проверки функциональности системы. Покройте тестами следующие сценарии:

1. **Тестирование класса Book**
   - Проверка создания книги с корректными данными
   - Проверка, что новая книга доступна по умолчанию

2. **Тестирование класса Reader**
   - Проверка, что читатель может взять книгу, если она доступна
   - Проверка, что читатель НЕ может взять больше 3 книг
   - Проверка, что читатель может вернуть книгу

3. **Тестирование класса Library**
   - Проверка добавления книги в библиотеку
   - Проверка регистрации читателя
   - Проверка поиска книги по названию
   - Проверка получения списка доступных книг
