# Исходное учебное задание

## Часть 1. Исправление логической ошибки

Найти и исправить ошибку во взаимодействии библиотеки и читателя.

## Часть 2. Модульные тесты

Используя MSTest, проверить:

- **Книгу:** создание с корректными данными и доступность по умолчанию.
- **Читателя:** возможность взять доступную книгу, ограничение в три книги и возврат.
- **Библиотеку:** добавление книги, регистрацию читателя, поиск по названию и список доступных книг.

В текущей реализации выдачей и возвратом управляет `Library`; `Reader` не хранит список книг.
